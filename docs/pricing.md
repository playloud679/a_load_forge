# src/pricing.py — retailer price records

Loading and safe matching of the optional `data/driver_prices.json`
dataset (generated by `tools/enrich_driver_prices.py` /
`tools/run_price_enrichment_cycle.py`), plus Safari-assisted TLHP catalog
offers generated by `tools/harvest_toutlehautparleur.py`, and the price-aware
value score.
`src/dccav.py` re-exports the public API; detailed contracts live in
`docs/dccav.md`.

## Owns

- `DRIVER_PRICES_PATH`
- `_load_driver_price_records()` (`lru_cache(maxsize=1)`): tolerant loader —
  a missing or corrupt file yields an empty mapping
- Safe matching: `_price_record_matches_preset` and its token helpers reject
  accessories/crossovers/recone kits and weak substring matches so a record
  only prices the preset it truly names. Matching recognizes model-code spans
  inside descriptive source titles, normalizes known brand aliases and always
  requires brand evidence for catalog-generated records. Explicit nominal
  impedances must agree, preventing a 4/8/16-ohm variant from borrowing a
  sibling variant's offer.
- `_preset_price(name, model, brand) -> (price | None, currency, url)`
- `parse_ecb_reference_rates(payload)`: parses the ECB daily XML feed into a
  EUR-based rate table and its published reference date
- `load_ecb_reference_rates(timeout_s=3)`: downloads the current ECB daily
  reference rates; network or malformed-feed failures return an empty result
  so the library remains usable offline
- `convert_price(price, source_currency, target_currency, rates)`: converts
  through the EUR-based table; same-currency prices need no live rate and an
  unavailable cross-rate returns `None`
- `price_extension_score(f3_hz, price)`: the lower-is-better `F3 × price`
  value score used by the Finder's `Best value` ranking

## Invariants

- Never imports `engine` or `presets` (leaf module; numpy only).
- Prices are advisory metadata: absence must never break preset loading or
  simulation paths.
- Exchange rates are volatile display/filter metadata, cached by the Streamlit
  UI for six hours. The UI exposes the ECB reference date and never substitutes
  an invented fallback rate after a download failure.
- The enrichment crawler percent-encodes non-ASCII characters found in
  retailer sitemap/category URLs while preserving existing `%xx` escapes, so
  typographic size fractions such as `6\u00bc` cannot abort a provider worker.
- Importable both as `src.pricing` and top-level `pricing`.
