# Bass Match — nine screenshot presets

Load these files from **Project → Load preset** in numeric order. They share a
10–500 Hz simulation window, 600 points, 2.83 V input and automatic F3/F6/F10
markers so screenshots can be compared directly.

| File | Driver | Load |
|---|---|---|
| `01_kef_b110_sealed.lfp` | KEF B110B article example | Sealed |
| `02_fostex_fe126_infinite_baffle.lfp` | Fostex FE126NV2 | Infinite baffle |
| `03_beyma_12cmv2_reflex.lfp` | Beyma 12CMV2 | Bass reflex, port |
| `04_dayton_rss315ho_passive_radiator.lfp` | Dayton Audio RSS315HO-4 | Bass reflex, passive radiator |
| `05_scanspeak_30w_dccav.lfp` | Scan-Speak 30W/4558T00 | DCCAV |
| `06_beyma_12lex1300_bp4.lfp` | Beyma 12LEX1300Nd | Bandpass 4th order |
| `07_lavoce_wsf122_bp6.lfp` | LaVoce WSF122.02 | Bandpass 6th order |
| `08_sb34swpl_sealed.lfp` | SB Acoustics SB34SWPL76-4 | Sealed |
| `09_dayton_um12_dccav.lfp` | Dayton Audio UM12-22 | DCCAV |

Each file uses a manual starter alignment so loading is immediate and does not
silently re-optimize between screenshots. Use **Pin current response** before
loading the next file when a multi-system overlay is useful.
